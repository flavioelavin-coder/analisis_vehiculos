# Análisis de ventas en vehiculos 🛒

## 🧩 Problema
El objetivo de este proyecto es analizar las ventas de marcas y tipos de vehiculos para identificar patrones de consumo y oportunidades de mejora.

## 📊 Dataset
vehicles_us.csv 

## 🧠 Stack / Herramientas
- Python
- Pandas, NumPy  
- Plotly  
- Streamlit

## 📈 Resultados
- Identificación de productos con mayor margen de ganancia
- Tendencias de ventas   
- Creación de dashboard interactivo con Plotly
